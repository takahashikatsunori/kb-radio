小平の暮らしと魅力の深掘りレポート

西武国分寺線・小川駅から徒歩約5分、小平市小川東町3-1-1にある「Bridgestone Innovation Gallery」は、世界的なタイヤ・ゴムメーカーの技術開発拠点に隣接した一般公開ミュージアムです。入館無料で、個人利用なら事前予約なし（月〜土 10:00〜16:00・最終入館15:30／日祝・年末年始休館）で気軽に本物の技術に触れることができます。

注目したい展示の一つが、タイヤだけでなく地震から病院・高層ビル・橋を守る「免震ゴム（免震支承）」などの防災・安全技術です。ゴムが地震の激しい揺れを吸収して建物へ伝わりにくくする仕組みは、月曜日の地震・建築テーマでもリスナーから関心の高いポイント。年末・年始の休館日カレンダーは公式サイトで事前にチェックしてお出かけください。
