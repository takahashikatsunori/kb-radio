小平の暮らしと魅力の深掘りレポート

小平市域を東西に横断し、小川東町の歴史交差点「九道の辻」を抜けて東村山方面へ続く「野火止用水緑道」は、江戸時代前期の承応4年（1655年）に川越藩主・松平伊豆守信綱（知恵伊豆）によって開削されました。玉川上水からの分水として新田開発の農地と住民の生活を支え、「伊豆殿堀」の名で長く親しまれてきました。

戦後の都市化と昭和48年（1973年）の渇水などにより分水が止まり一度流れが途絶えましたが、市民や自治体による熱心な保全運動が実を結び、昭和59年（1984年）の東京都「清流復活事業」によって高度処理水による清流が復活しました。今は「小平グリーンロード」の大切な一部として多くの人に歩かれており、平時から徒歩移動路や排水ルートを確かめる散歩にも最適です。

🎙️ 小春＆平蔵の取材メモ：九道の辻の『迷いの桜』伝説から1984年の清流復活まで、歩くたびに時代を超えた人々の想いに触れられる小平屈指のストーリー散策路です。
